# Boot IDE

Boot IDE é um editor de código puramente feito em Java.
Se você curte pixels e programação, essa é a opção certa!

## Como Usar

Você pode clonar o código do GitHub e compilá-lo no seu computador, ou acesse o
site da Boot IDE (Ele ainda não existe) e baixar a versão já compilada!

## Como Compilar

Coloque o projeto na pasta eclipse-workspace e crie um projeto com ela.
Depois clique no projeto uma vez e execute-o clicando no botão de Executar do Eclipse.

## Quando abrir, o que faço?

Na primeira vez que você abre a Boot IDE, não tem nenhuma pasta carregada, então clique no
botão "Selecionar Pasta Base" e selecione uma pasta. Depois, navegue pelas pastas e clique
no arquivo que deseja editar, depois comece a programar!
